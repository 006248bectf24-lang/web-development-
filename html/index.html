Task 1: Revision of Class 1 & Class 2

1. What is Web Development?

Web Development is the process of creating, designing, developing and maintaining websites and web applications. It includes frontend, backend and database development.

2. Static vs Dynamic Website

A Static Website displays the same content to every visitor and does not use a database. A Dynamic Website changes its content according to the user and uses databases.

3. Frontend, Backend and Full Stack Development

Frontend is the visible part of a website developed using HTML, CSS and JavaScript. Backend is the server-side part that manages data and databases using languages like PHP, Python and Node.js. A Full Stack Developer works on both frontend and backend.

4. Technology Stack

A Technology Stack is a collection of programming languages, frameworks, databases and tools used to develop a website. Example: HTML, CSS, JavaScript, Node.js and MySQL.

5. Git vs GitHub

Git is a Version Control System used to track code changes. GitHub is an online platform used to store and share Git repositories.

6. Purpose of VS Code

Visual Studio Code (VS Code) is a free code editor used to write, edit and debug programming code.

Semantic HTML uses meaningful tags such as header, nav, main, section, article and footer to organize a webpage. It improves readability, accessibility and SEO.
